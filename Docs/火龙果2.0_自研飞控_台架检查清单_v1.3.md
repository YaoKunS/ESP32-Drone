## 🔴 起飞前必查三件事（侧翻 / 解不开锁，九成出在这）

| # | 查什么 | 怎么查 | 通过标准 |
| --- | --- | --- | --- |
| 1 | **水平校准有没有做** | 机架放平 → 网页「设置」→ 姿态球读数 | 横滚 / 俯仰都在 **±2°** 内。整片刷过固件（NVS 被清）必须重做「水平校准」，否则姿态环带着虚假倾角起飞 → **固定方向侧翻**（v1.2 实测踩过） |
| 2 | **电机位置 + 转向** | 拆桨，网页「测试」逐路点（第 5 节） | 点哪个按钮只有对应那个角转；转向符合 X 型（对角同向、相邻反向） |
| 3 | **遥控链路活着** | 网页摇杆推一点，看姿态/电机响应；看 `链路超时` 是否归零 | 摇杆动则电机响应；**默认 300ms 收不到指令就自动上锁**——台架测时别让网页断开超 0.3 秒 |

> 1、2 全过 = 默认参数就能飞。**自研飞控没有串口命令行**（没有 `imu` / `p` / `cr` 这类命令），
> 所有配置、校准、测试全部在网页 `http://192.168.4.1` 里做，串口只输出日志。

### 烧录速查

**方式 A：Flash Download Tool** —— 芯片选 **ESP32**（⚠️ 不是 ESP32-S3）/ Develop 模式 / 只加整片 bin / 地址 **`0x0`**。

**方式 B：esptool**

```bash
# 整片烧（会清 NVS：标定、热点名、PID 全回出厂）——新板或要重置时用
python -m esptool --port COMx --baud 460800 --after hard-reset \
  write-flash 0x0 YaoKunS_HLG2_YaoKunDrone_FW_v1.3_20261117_merged.bin

# 只更 app（NVS 全保留，日常升级用这个）
python -m esptool --port COMx --baud 460800 --after hard-reset \
  write-flash 0x10000 YaoKunS_HLG2_YaoKunDrone_FW_v1.3_20261117_app_0x10000.bin
```

> 🔴 单独烧 bootloader 时地址是 **0x1000**，不是 S3 的 0x0（照抄会「verified 但不启动、串口 0 字节」）。
> 🔴 整片 0x0 刷写会把 0x9000~0xE000 的 nvs 一起写成 0xFF ⇒ **刷完必须重做陀螺仪校准 + 水平校准**。

## 2. IMU 识别与方向（网页「设置」看姿态球）

`IMU axis map:` 那一行会打印本次判定结果，先看它，再看姿态球：

| 你插的模块 | 期望日志 | 总线 / 引脚 |
| --- | --- | --- |
| MPU6500 / MPU9250（SPI 座） | `SPI 6500-family (WHO=0x70)` → `Detected MPU6500 (SPI)` | SCK18 / MISO19 / MOSI23 / **CS5** |
| MPU6050 进口 / 国产克隆（I2C 排母） | `I2C 6050-family (WHO=0x68)` / `(WHO=0x70)` | SDA21 / SCL22 |

**方向判据（本工程约定，不是民航习惯，2026-11 三模块实测确认）：**

- [ ] 机身**向左倾斜 ~30°** → 横滚（Roll）为**负**，地平线左低右高
- [ ] **抬头** → 俯仰（Pitch）为**正**，姿态球显示天空
- [ ] **低头** → 俯仰为**负**
- [ ] 平放静止 → 横滚 / 俯仰都在 **±2°** 内
- [ ] yaw 读数在 6050 与 6500 之间天然反号（两代芯片陀螺 Z 极性相反），**属正常，不影响控制**

> 🔴 换 IMU 模块、整片刷固件、拆装过 IMU 座之后，**必须重做「水平校准」**（设置页）。
> 姿态是 `原始欧拉角 − 水平零偏` 算出来的，零偏归零而板子在机架里不是绝对水平 ⇒ 起飞瞬间固定方向猛纠 ⇒ 侧翻。

## 3. 电压检测

- [ ] 网页遥测里电池电压与万用表实测一致（±0.05 V 内；分压系数 2.0 已按 GPIO35 的 100K+100K 配好）
- [ ] 拔电池后读数掉到 0 附近（不卡旧值）
- [ ] 告警门槛（1S 电芯）：< 3.7 V 慢闪 / < 3.5 V 中速闪 / < 3.3 V 快闪 + 蜂鸣

> 🔴 GPIO35 是 **input-only + ADC1**。ADC2 与 Wi-Fi 互斥（本固件热点常开），
> 若把电压检测挪到 ADC2 会恒读 0 ⇒ 误判低电 ⇒ 蜂鸣器无限急鸣。

## 4. 网页控制链路

- [ ] 连上热点后 `http://192.168.4.1` 能打开，姿态球随板子转动实时更新
- [ ] 「遥控」页：左杆（油门 / 偏航）、右杆（俯仰 / 横滚）能拖动，网页显示值与遥测一致
- [ ] 点「ARM解锁」→ 灯转常亮、蜂鸣三声；点「紧急上锁」→ 立即断输出

> ⚠️ **自研飞控的遥控超时默认只有 300 ms**（`cmd_timeout`，网页「设置」可调到 2000 ms）。
> 这是为有线/低延迟链路设的；用网页摇杆飞时 Wi-Fi 抖一下就自动上锁。
> **台架测先把它调到 2000 ms**，真机试飞前再评估（网页遥控不适合大油门飞行）。

网页「测试」页，油门默认 0.05、上限被固件限死 **0.20（20%）**，单次 100~2000 ms，随时可按「停止」。

| --- | --- | --- |
| M4 左前 | 左前 | **32** |
| M1 右前 | 右前 | **33** |
| M2 右后 | 右后 | **27** |
| M3 左后 | 左后 | **26** |

- [ ] 四个按钮逐个点，**只有对应那个角转**（点 M1 转的是右前；转错位置 ⇒ 引脚/接线错，不要飞）
- [ ] 转向符合 X 型：**对角同向、相邻反向**
- [ ] 每路都能持续转满设定时长，无重启、无 `LEDC` 报错
- [ ] 断电手拨四桨：转动顺滑、无卡滞、无异响

> 🔴 **「看电池电压掉不掉来判断电机转没转」是假判据**——台架插 USB 时电机吃的是 USB 5V→LDO，电池端本来就不掉压。
> 真判据：听声音 / 看电机 / 摸驱动管；要看电压就先拔 USB 只留电池。

**装桨验风向（手托机架，低油门，桨下方无人）：**

- [ ] 四只桨**都向下吹风**；任一只向上 ⇒ 桨装反（换另一片）或电机两根线对调
- [ ] 手拨桨：桨叶前缘朝旋转方向，能「切」风不「兜」风

## 6. 灯语（单灯板型，靠闪频区分）

本板只有一颗灯（GPIO2，**高电平点亮**）。三色语义按「谁要亮就亮」合成：

| 状态 | 单灯表现 | 含义 |
| --- | --- | --- |
| 启动中 | 半亮 / 全亮交替（周期 220 ms） | 上电自检 |
| 已上锁（待机） | 呼吸渐变（约 1.4 s 一轮） | 等解锁 |
| 解锁等待 | 慢闪（300 ms） | 正在解锁（保持开关） |
| 已解锁 | 常亮 | 可以起飞 |
| 故障保护 | 快闪（120 ms） | 超时 / 倾斜 / IMU 异常 |

- [ ] 上电灯是交替闪（不是常灭、不是常亮）
- [ ] 解锁后常亮，上锁后回到呼吸
- [ ] 低电时灯转慢闪（配合蜂鸣）
- [ ] 灯不闪但系统正常 ⇒ 检查 GPIO2 限流电阻 / 灯珠极性（拉电流接法，高电平亮）

## 8. 安全逻辑（台架必测，别跳过）

| 项 | 操作 | 期望 |
| --- | --- | --- |
| 遥控超时 | 解锁后关掉网页 / 断 Wi-Fi | 超过 `cmd_timeout`（默认 300 ms）**立即上锁**、灯快闪、蜂鸣急鸣 |
| 倾斜保护 | 解锁后把机架歪过 80° | 立即上锁 + 快闪 |
| 油门不在低位 | 油门推中间再点解锁 | 拒绝解锁（不转灯常亮） |
| 紧急上锁 | 飞行中（台架用低油门）点「紧急上锁」 | 电机立即停 |

> 🔴 **自研飞控的失联策略是「立即上锁」，不是缓降**。真机飞行时链路抖动 = 直接掉下来，
> 所以：① 试飞时 `cmd_timeout` 不要太小；② **不要在 QGC/地面站里开虚拟摇杆**（自研固件不支持，且会抢控制源）。

## 9. 长跑与稳定性

- [ ] 连续通电 **> 72 分钟**：网页遥测不断、姿态不漂、时间单调递增不回落
- [ ] 触摸电机驱动 / LDO 温升正常（不烫手）
- [ ] 反复上电 10 次，每次都能进 `Ready`（排除供电浪涌导致的偶发不启动）

> 旧版 32 位 `micros()` 每 71.58 分钟回绕会导致门控停摆（遥测停、终端仍回显）。v1.2 起用 64 位累加器，本项是回归证明。

## 10. 实测中容易误判的「假 bug」

| 现象 | 真相 |
| --- | --- |
| 网页「采样频率」显示 20 Hz | 它是**主循环频率**，不是 IMU ODR，正常 |
| 串口日志先报 I2C 失败再报 SPI 成功 | **正常回退流程**：I2C 排母为空 → 读 0xFF → 换 SPI 命中 |
| 网页摇杆一松手电机就停 | 油门回中即 `throttle <= kArmThrottleMax` ⇒ 强制停转，属设计 |
| 网页显示 `链路超时` 一直涨 | 网页断连了（Wi-Fi 掉 / 手机省电锁屏）；重连后归零 |
| 电机转了但电池电压没掉 | 插着 USB，电机吃 5V（见第 5 节） |
| 姿态球 yaw 一直慢漂 | 无磁力计，纯陀螺积分必然漂，正常（本固件没有航向保持） |
| 单灯只有亮/灭，没有红绿交替 | 单灯板型把三色合成一颗灯，交替退化为「半亮/全亮」，闪频语义没丢 |

## 11. 出问题怎么查

| 现象 | 先看什么 |
| --- | --- |
| 烧录 verified 但不启动 | 芯片是否选成 ESP32-S3；bootloader 是否烧到 0x0（应 0x1000）；整片 bin 从 0x0 烧最稳 |
| 横幅显示 `YaoKun S3` | 烧错固件了，这是火龙果整片 bin |
| `LEDC attach` 出现 0 | 该路引脚被占用或非法（经典片 >39 的脚） |
| 找不到热点 | 串口看有没有 `AP IP: 192.168.4.1`；Wi-Fi 初始化失败通常是供电不足 |
| 网页打不开 | 手机是否连的是 `YaoKun_Drone`；浏览器用 `http://` 不是 https |
| 姿态球不动 / 全 0 | IMU 没认到：看 `Detected` 那行；查 SPI 18/19/23/CS5 或 I2C 21/22 焊接 |
| 姿态球方向反 | 对照第 2 节判据；换过模块要重做水平校准；仍反则发我 `IMU axis map` 那行 |
| 电机不转 | 是否已解锁；油门是否 >0.02；`LEDC attach` 是否 1；单测哪一路 |
| 起飞就翻 | ①水平校准没做 ②电机位置/转向错 ③桨装反 —— 按此顺序查，别先怀疑参数 |
