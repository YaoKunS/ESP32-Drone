二、烧录方法
--------------------------------------------------------------
方式 A：Flash Download Tool（图形界面，推荐）
  1. 芯片选 ESP32（不是 ESP32-S3！）、Develop 模式、波特率 460800
  2. 只添加 YaoKunS_HLG2_YaoKunDrone_FW_v1.3_20261117_merged.bin，地址填 0x0
  3. START，等 FINISH 后按 RST

方式 B：esptool
  整片：esptool --port COMx --baud 460800 --after hard-reset ^
        write-flash 0x0 YaoKunS_HLG2_YaoKunDrone_FW_v1.3_20261117_merged.bin
  只更app：esptool --port COMx --baud 460800 --after hard-reset ^
        write-flash 0x10000 YaoKunS_HLG2_YaoKunDrone_FW_v1.3_20261117_app_0x10000.bin

  ※ 本板 bootloader 地址是 0x1000（经典 ESP32 规则），S3 才是 0x0。
  ※ 串口芯片是 CH340。别在串口助手里手动拉 DTR/RTS，会按进复位。

四、刷完必须做的两件校准（否则起飞瞬间侧翻）
--------------------------------------------------------------
整片刷写清空了 NVS 里的水平零偏。姿态 = 原始欧拉角 − 水平零偏，
零偏归零而机架不是绝对水平 ⇒ 姿态环带着虚假倾角起飞猛纠 ⇒ 固定方向侧翻。

  1) 机架放平 → 网页「设置」→ 陀螺仪校准（期间不要动板子）
  2) 同一页 → 水平校准 → 确认姿态球横滚/俯仰在 ±2 度以内
  3) 改过 PID/限制参数后点「保存参数」，否则重启即丢

--------------------------------------------------------------
六、本版（v1.3）改了什么
--------------------------------------------------------------
  1. 新增微辣火龙果 2.0 板型（PCB_HLG_V2）：电机/IMU/ADC/蜂鸣器/灯全部按本板引脚；
     与 S3 版共用同一套混控与控制算法（两板电机布局、IMU 装向、桨装法一致）。
  2. 单灯合成层：只有一颗灯，红/绿/蓝三路语义按「谁要亮就亮」合成到 GPIO2，
     闪频语义保留（启动交替、待机呼吸、解锁常亮、故障快闪）。
  3. 火龙果专属品牌横幅：显示火龙果品牌与立创开源/B站链接，末尾保留耀坤淘宝行。
  4. S3 版无功能变化：仅版本号与新增 Board 行（便于现场区分两套固件）。
  5. 角速率环默认 PID 仍是 0.010 / 0 / 0.00008（v1.2 实飞验证值），本版未改。

七、排障速查
--------------------------------------------------------------
  烧完 verified 但不启动 / 串口 0 字节 → 芯片选成 S3，或 bootloader 烧到 0x0（应 0x1000）
  横幅 Board 显示 YaoKun S3 ............ → 刷错固件，重烧本包
  LEDC attach 出现 0 ................... → 该路 PWM 没绑上，电机不会转
  找不到热点 ........................... → 串口看有没有 AP IP 行；无则查供电
  姿态球方向反 ......................... → 先重做水平校准；仍反看 IMU axis map 行
  网页摇杆一停电机就停 ................. → 油门回中强制停转，属设计
  飞起来自动上锁 ....................... → cmd_timeout 默认 300ms，网页设置可调到 2000ms
