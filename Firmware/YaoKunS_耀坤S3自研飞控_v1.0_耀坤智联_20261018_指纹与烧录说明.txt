【一、这份固件是什么】
  纯自研 ESP32-S3 四轴有刷无人机飞控（工程名 YaoKunDrone），不是 ESP-Drone /
  LiteWing / Flix 的派生版本，控制算法、Web 遥控界面、音效灯效全部自研。
  硬件对应：立创 ESP32-S3 R8N8 开发板（8MB Flash + 8MB OPI PSRAM），
            即完整版 PCB「YaoKun_K1.0」（板型宏 PCB_YaoKun_LCKFB_ESP32S3）。
  传感器：MPU6050 / MPU6500 六轴（I2C，上电自动识别，WHO_AM_I 判定）。
  控制：串级双环 PID（角度环 → 角速度环 → 四轴混控）+ 姿态解算
        （互补滤波 / Mahony / Madgwick 可在网页里切换）。
  遥控：飞机自建 WiFi 热点，手机或电脑浏览器直接打开 192.168.4.1 遥控，
        WebSocket 双向通信（上行摇杆/命令，下行 20Hz 遥测），无需 App、无需遥控器。
  音效灯效：14 种蜂鸣音效（上电/解锁/起飞/低电/失联/校准…非阻塞状态机）
            + 红绿蓝三色灯语（红绿走 LEDC 硬件 PWM，蓝灯指示 WebSocket 连接）。
  界面：Android 风格 Web UI，12 套主题，姿态球（ADI 民航姿态仪风格）。
  不含：MAVLink / CRTP / SBUS / 光流 / 气压计（本版本为纯姿态自稳 + 手动油门）。

  ★ 默认热点：SSID = YaoKun_Drone   密码 = 12345678
    （刷完后手机连该热点，浏览器访问 http://192.168.4.1/ 即可）

  ★ 本固件只适配「立创 ESP32-S3 R8N8 全功能板」这一种板型。
    若你的机器是 Supermini 版（S1.0A / S1.0B / S1.0C），马达与传感器引脚不同，
    直接刷本固件会出现电机不转或姿态错乱，必须改 config.h 的板型宏后重新编译。

【三、怎么烧（Flash Download Tool）】
  1) 打开 Flash Download Tool，芯片选 ESP32-S3，工作模式 Develop。
  2) 只添加这一个文件，地址填 0x0 ：
       YaoKunS_耀坤S3自研飞控_v1.0_耀坤智联_20261018_merged.bin
  3) 设置：SPI SPEED = 80MHz ，SPI MODE = DIO ，
           FLASH SIZE = 8MB（16MB 的板子也选 8MB） ，
           COM 口选你的板子，BAUD 选 921600（不稳就降到 115200）。
  4) ⚠️ 务必勾选 DoNotChgBin 。
     原因：镜像头里已写好 SPI 模式/频率/容量（DIO 80MHz 8MB）与镜像尾部 SHA-256，
           工具若按所选参数改写头部，会破坏校验和导致无法开机。勾上就按原样写入。
  5) 点 START 等待完成，然后按 RST 或重新上电。

  · 用 esptool 一条命令也行（等价）：
      esptool --chip esp32s3 --port COMx --baud 921600 write_flash 0x0 ^
        YaoKunS_耀坤S3自研飞控_v1.0_耀坤智联_20261018_merged.bin

  · 烧完若「不跑、停在下载模式」（日志出现 waiting for download）：
    说明 GPIO0 被拉低没放开。先 --after no-reset 连一下确认镜像可读，
    再执行 esptool --after watchdog-reset run，或直接拔插 USB / 按 RST。

【六、六点须知】
  1) 单文件从 0x0 整片刷写，会把 0x9000~0x10000（nvs：WiFi 校准数据 + 已保存参数）
     一并写成 0xFF，等于清空。刷新板/空板无影响；刷自己已经调好 PID 的机器要留意，
     这种场合请改用分片写（只写 0x0 / 0x8000 / 0xE000 / 0x10000 四段，跳过 0x9000）。
  2) 本版分区方案为 no_ota（单 app 2MB），没有 OTA 分区 —— 升级只能重新插线刷写。
  3) 编译时 CDCOnBoot=cdc：Serial 输出走原生 USB 口。如果你只插了板上的 UART 口，
     看不到开机日志是正常的，改用原生 USB 口即可。
  4) FLASH SIZE 请按 8MB 选；16MB 的板子（N16R8）也能刷，只是后 8MB 用不到。
  5) 本机是「纯姿态自稳 + 手动油门」，没有 GPS / 气压计 / 测距 / 光流，
     松杆不会悬停（保持既有水平速度继续飘），松油门就会掉高度；首次试飞请在
     空旷场地、低空、有保护圈的前提下进行，并先确认网页里「解锁」与「上锁」正常。
  6) 网页里改了 PID / 校准参数会自动存 NVS，下次上电仍在；要恢复出厂用网页的
     「恢复默认」按钮（不要用整片刷写来"恢复"，那会连带清掉 WiFi 校准）。
